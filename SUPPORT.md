# Support

WHOOP Personal MCP is a community-maintained, self-hosted project with no
guaranteed response time or service-level agreement.

- Setup, deployment, or usage problem: read
  [docs/troubleshooting.md](docs/troubleshooting.md), then open a
  [GitHub issue](https://github.com/josealvaradoa/whoop-personal-mcp/issues).
- Reproducible bug: include the version/commit, Node or container version,
  deployment type, client name, the failing step, HTTP status, and redacted
  logs.
- Feature request: explain the personal use case and why it fits the
  single-user, read-only scope.
- Security vulnerability: use the private process in
  [SECURITY.md](SECURITY.md), not a public issue.
- WHOOP account, API approval, or platform incident: contact WHOOP through its
  own support channels. The repository maintainers cannot access your WHOOP
  account.
- Client/model or hosting incident: contact that provider. The maintainers
  cannot inspect or delete provider-side data.

Never post <code>.env</code>, the SQLite database, OAuth codes/tokens, client
secrets, access passwords, bearer tokens, or unredacted wellness data.
