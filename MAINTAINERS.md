# Maintainers

| Maintainer | Role | Responsibilities |
|---|---|---|
| [`@josealvaradoa`](https://github.com/josealvaradoa) | Lead maintainer | Repository administration, releases, security response, and contribution review |

Maintainers are added or removed through a pull request that updates this file
and [`GOVERNANCE.md`](GOVERNANCE.md). A candidate should have a sustained record
of constructive contributions, understand the project's privacy and security
boundaries, and explicitly accept the responsibilities in the governance
policy.

The project currently has one maintainer. Branch protection therefore requires
all changes to use a pull request and pass automated gates, but does not require
an approval the author cannot give themselves. After a second active maintainer
is added, require at least one approval and code-owner review on `main`.
